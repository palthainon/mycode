    How to play. Type commands like look, north, examine desk, take lantern or help. Shell habits work too: ls, cd .., cat note, man go. Prefer buttons? Switch to choice mode and press 1–9.

    • You have 3 lives for the whole game (the knight has 4). A wrong answer costs one. Lose them all and the current act restarts.
    • Wizards get one free hint per act. Rogues can sneak past one guardian per act.
    • Each realm hides one potion. Drink it for a life, or trade it for a hint.
    • Poke around. Rooms hide curios (useless, but counted), things look different the second time, and listen, smell and touch work. Some details don't add up; notes keeps track of them.
    • Progress saves at the start of each act, in this browser only. ↑ recalls earlier commands.
