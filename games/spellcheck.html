Spellcheck: a wizard typing game

Enemies walk toward the wizard, each carrying an IT word, Linux command or PowerShell cmdlet depending on the word set you pick. Type a word to cast a spell at that enemy. Press Enter to start, Escape to pause. The game area takes keyboard input once you click it or start typing.
