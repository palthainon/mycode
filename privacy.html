privacy

What this site collects, and who it talks to.

the short version

  • The tools run in your browser. What you type, paste or open in a tool stays in the tab, with the exceptions listed under outside services.
  • No accounts, no ads, no cookies set by this site or its analytics.
  • The site counts page views and errors with Microsoft Azure Application Insights, with cookies switched off. The details are below.

anonymous page statistics

Every page loads a small script that sends usage data to an Azure Application Insights resource run by the operator of this site. It is used to see which tools get used and which pages break. It records:

  • the page address, including anything after a ? in it (for example a source tag on a printed QR code), and the page that referred you;
  • page load timing, browser, operating system and device type;
  • an approximate location (country, region, city) that Microsoft works out from your connecting IP address. Microsoft's documentation says Application Insights keeps the address itself out of storage by default and writes 0.0.0.0 instead (Azure Monitor: geolocation and IP handling);
  • JavaScript errors raised on the page.

It does not record what you enter into a tool, and request tracking is turned off, so the addresses you look up on the My IP tool are not logged here. The script sets no cookies and no per-visitor identifier is stored on your device. It can hold events in your browser's session storage until they are sent.

To opt out, block js.monitor.azure.com in your browser or content blocker. The tools keep working without it.

MCP experiment

The MCP services process requests on an Azure server. Submitted logs, email headers and delivery logs, captured HTTP metadata, JSON configuration/schema inputs and network plans are processed transiently and are not saved. Email tracing, capture analysis and configuration validation make no external requests. Remove credentials and sensitive material before submission; excerpt redaction is limited and is not a complete secret scanner. DNS checks send the requested domain to Google Public DNS; HTTPS and deployment-readiness checks also contact the public website. Those services receive the query or request and our server's connecting address.

Dedicated Azure Application Insights telemetry records service and tool names, protocol actions, outcomes, timestamps, durations, input/output sizes and client-reported software name/version when supplied during initialization. We do not log submitted tool arguments or results, queried domains, full request URLs, raw source IP addresses, or unfiltered errors.

To estimate repeat use, the service derives a pseudonymous identifier from your source IP address and user-agent using an experiment-specific secret. It stores the derived identifier, not the source address. This is approximate: shared networks and changing addresses can combine or split caller groups. Client software names are self-reported.

Telemetry is retained for 60 days. Generic probes are counted in aggregate. Internal tests are marked and excluded from adoption reports. Azure necessarily processes connection metadata to operate the service. Application logging and diagnostics are configured to minimize collected data. No cookies or user accounts are used.

what stays on your device

Tools save preferences and form entries in your browser's local storage, under keys that start with owt_. This includes your pinned tools and your theme choice. It never leaves your browser. Each tool that saves entries has a Clear Saved Data button, and clearing your browser's site data removes the rest.
